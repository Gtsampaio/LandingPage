# Landing Page – HTML e CSS

Este repositório contém uma landing page desenvolvida com HTML e CSS como atividade prática durante o curso do **Instituto PROA**. O projeto tem como objetivo praticar e aprimorar conhecimentos em desenvolvimento web, estruturação de conteúdo e estilização de interfaces, sendo realizado para fins educacionais e de treinamento.

## Funcionalidades

- **Estrutura HTML:** Organização do conteúdo utilizando elementos HTML.
- **Estilização com CSS:** Aplicação de cores, fontes, espaçamentos e elementos visuais para compor a interface.
- **Organização de Seções:** Distribuição dos elementos em áreas distintas para facilitar a leitura e a navegação.
- **Elementos Visuais:** Utilização de imagens, textos e componentes para tornar a página mais atrativa.
- **Layout da Página:** Construção de uma interface organizada para apresentar informações de maneira clara.

## Objetivo do Projeto

O projeto foi desenvolvido com finalidade educacional e de aprendizado, visando consolidar conhecimentos fundamentais em HTML e CSS por meio da criação de uma landing page. A atividade também contribui para o desenvolvimento de habilidades de estruturação, organização e estilização de páginas web.

## Tecnologias Utilizadas

- **HTML5:** Estruturação e organização do conteúdo da página.
- **CSS3:** Estilização e apresentação visual da interface.

## Como Executar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em um navegador para visualizar a landing page.

## Aprendizados

Durante o desenvolvimento, foram praticados conceitos de estrutura HTML, organização de conteúdo, seletores CSS, aplicação de estilos, espaçamentos e construção de interfaces web.

## Referência e Créditos

Projeto desenvolvido para fins educacionais, com base no tutorial [LANDING PAGE COM HTML e CSS!](https://www.youtube.com/watch?v=llF6vD-RljE), disponível no YouTube. O código foi acompanhado e reproduzido com o objetivo de praticar os conceitos de HTML e CSS apresentados.
